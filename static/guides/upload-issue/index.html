Как загрузить выпуск Journal XML и PDF в ИС «Метафора»

Сначала отправьте XML выпуска. После обработки сопоставьте PDF с созданными статьями и проверьте пары перед загрузкой.

Открыть загрузку

Подготовьте XML выпуска и PDF статей

  • Возьмите один файл Journal XML в формате РИНЦ по схеме journal3.xsd. Корневой элемент файла – <journal>.
  • Подготовьте отдельный PDF для каждой статьи. Сверьте DOI в метаданных XML и на первой странице PDF.
  • В консоли «Метафоры» введите API-ключ вашей организации и нажмите «Сохранить и проверить».

Загрузите выпуск и проверьте пары

  1. На вкладке «Загрузка» выберите «Выпуск с PDF» и добавьте XML выпуска и PDF статей.
  2. Нажмите «Загрузить XML выпуска» и дождитесь окончания обработки. В таблице появятся статьи, созданные из XML.
  3. Проверьте предложенные пары по DOI и заголовкам. Нажмите на название статьи, чтобы сверить метаданные с PDF. При необходимости выберите другой файл в таблице.
  4. Нажмите «Загрузить PDF к … статьям» и проверьте результаты в таблице. Если один PDF назначен нескольким статьям, консоль остановит отправку и покажет строки с конфликтом.

Пример. В выпуске 16 статей. У них общий file_uid исходного XML, а у каждой статьи свой article_uid. PDF прикрепляется к статье по её article_uid.

Если XML выпуска уже загружен

Откройте вкладку «PDF», вставьте DOI статей по одному на строку и нажмите «Найти статьи». Добавьте PDF, проверьте пары и нажмите «Прикрепить PDF». Этот способ подходит для публикаций без PDF, которые ещё не подписаны.

Чтобы проверить один результат, найдите статью на вкладке «Публикации» и нажмите «Скачать PDF» в её карточке.
